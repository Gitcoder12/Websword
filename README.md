AI-powered content detection with explainable classification and confidence scoring.

## Overview

Websword is an AI-powered web application that analyzes text and estimates whether it was written by a human or generated by an AI system.

The platform provides:

* Binary classification (`Human` or `AI`)
* Confidence score (0–100%)
* Explainable insights describing the factors influencing the prediction
* Web interface and API access
* Optional client-side inference for privacy-sensitive deployments

Websword is designed for educational, editorial, research, and content-review workflows.

## Installation

### Prerequisites

* Node.js 18+
* npm 9+

### Clone Repository

```bash
git clone https://github.com/your-username/websword.git

cd websword
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Application will be available at:

```text
http://localhost:3000
```

## Usage

### Web Interface

1. Open the application in a browser.
2. Paste or enter text.
3. Submit for analysis.
4. Review:

   * Prediction
   * Confidence score
   * Explanation

### Recommendations

| Parameter      | Recommendation  |
| -------------- | --------------- |
| Language       | English         |
| Minimum Length | 50+ characters  |
| Ideal Length   | 200+ characters |
| Input Format   | Plain text      |

English-language content generally produces the most reliable results.

## API Usage

### Endpoint

```http
POST /api/detect
```

### Request

```json
{
  "text": "This is the text to analyze."
}
```

### Example cURL

```bash
curl -X POST http://localhost:3000/api/detect \
-H "Content-Type: application/json" \
-d '{
  "text":"This is the text to analyze."
}'
```

### Response

```json
{
  "prediction": "AI",
  "confidence": 94.3,
  "explanation": "Consistent sentence structure and low stylistic variance contributed to the classification."
}
```

## API Reference

### POST `/api/detect`

Analyze text and return a classification result.

#### Request Body

| Field | Type   | Required | Description             |
| ----- | ------ | -------- | ----------------------- |
| text  | string | Yes      | Text content to analyze |

#### Response Fields

| Field       | Type   | Description                              |
| ----------- | ------ | ---------------------------------------- |
| prediction  | string | `Human` or `AI`                          |
| confidence  | float  | Confidence score between 0 and 100       |
| explanation | string | Human-readable explanation of the result |

#### Status Codes

| Code | Description                |
| ---- | -------------------------- |
| 200  | Successful analysis        |
| 400  | Invalid request            |
| 413  | Input exceeds allowed size |
| 429  | Rate limit exceeded        |
| 500  | Internal server error      |

## Privacy and Deployment Options

### Client-Side Inference

Using Transformers.js:

* Analysis occurs entirely in the user's browser
* No text is transmitted to external servers
* Suitable for privacy-sensitive environments

### Server-Side Inference

Using Python or Node.js:

* Centralized model management
* Easier monitoring and updates
* Better support for larger models

---

## Limitations

* Detection results are probabilistic and not definitive proof of authorship.
* Performance is strongest on English-language content.
* Very short inputs may produce unreliable predictions.
* Heavily edited AI-generated text can be more difficult to classify.
* Detection accuracy may vary across domains, writing styles, and model generations.
