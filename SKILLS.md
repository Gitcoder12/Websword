# Agent Skills — Websword

Map actual text features and scoring functions to their source implementation.

## Evaluation design
Define labelled data, splits, baselines, metrics, calibration and uncertainty.

Flag high-stakes claims and propose safer presentation of uncertainty.

## Documentation
Explain the UI to beginners and formulas/evaluation to technical reviewers.
