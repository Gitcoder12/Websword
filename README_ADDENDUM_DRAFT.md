# Websword — README Explanation Draft

## In plain language

A browser tool that examines writing patterns and shows heuristic signals that may be associated with AI-generated text.

## What it does

The user pastes text into a browser page. The page calculates simple signals based on the current implementation and displays an estimate. That estimate is not proof of who wrote the text.

## Technical explanation

A static HTML/CSS/JavaScript prototype that accepts pasted text and reports heuristic writing-pattern signals. It is not a reliable AI detector, cannot determine authorship, and must not be used for academic, employment or disciplinary decisions without independent evidence.

Document every extracted feature, formula, normalisation step, input boundary and output field. Explain the dataset used for evaluation and any known domain shift.

## Responsible use

Never use a score as the sole basis for grading, hiring, discipline, moderation or allegations of plagiarism. State uncertainty and known failure modes prominently.
