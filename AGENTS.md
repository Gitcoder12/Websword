# Agent Instructions — Websword

Read README.md, CONTRIBUTING.md and FEATURE_UPGRADE_PLAN.md before changes.

- Treat detector output as heuristic signals; never assert authorship or intent.
- Inspect the actual feature extraction and scoring logic before documenting it.
- Use appropriately licensed labelled data and preserve provenance.
- Add tests for short, long, unicode, empty and adversarially transformed text.
- Report false positives, false negatives, calibration and subgroup errors honestly.
- Never use private or scraped personal writing without permission.
- Work on a branch and open a PR; do not merge or deploy autonomously.
